## One 90-minute session

| Time | Work |
|---|---|
| 0–10 min | Read the brief and create `PLAN.md` inside the project folder. Write the input, output, rules, and three examples in your own words. |
| 10–25 min | Write pseudocode. Identify the smallest functions you need. |
| 25–55 min | Implement without AI. Run the program after every small change. |
| 55–75 min | Add tests for normal, boundary, and invalid cases. Fix failures yourself first. |
| 75–90 min | Refactor unclear names or repeated logic, complete `REFLECTION.md`, and commit the work. |

If you are genuinely stuck after 45 focused minutes, ask AI for **one hint**, not the solution. Show your attempt and explain exactly where your reasoning stops.

